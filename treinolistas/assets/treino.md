Exercício: Lista de Tarefas Dinâmica
Crie uma página simples em HTML e JavaScript que faça o seguinte:

Tenha um campo de texto e um botão “Adicionar”.

Quando o usuário digitar algo e clicar no botão:

Use append() para adicionar o texto diretamente dentro de uma <div> chamada mensagens.

Use appendChild() para adicionar o mesmo texto dentro de uma <ul> chamada lista.

Cada item adicionado deve aparecer tanto na div quanto na ul.

Diferencie o uso dos dois métodos:

Na div, o texto pode vir acompanhado de outros elementos (ex: emoji ou ícone).

Na ul, cada item deve ser um <li> criado dinamicamente.
